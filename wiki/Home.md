# Open Resistance

Open Resistance is an Insurgency-style game mode for Arma Reforger. Players are the **Resistance** (INDFOR, default FIA), fighting two AI armies: the **Occupiers** (BLUFOR, default US Army) and the **Invaders** (REDFOR, default Soviet Army). Each playthrough is a persistent campaign that a server admin creates or loads.
